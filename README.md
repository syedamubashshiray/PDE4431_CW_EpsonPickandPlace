## Coursework Overview

This repository contains the programming work completed as part of the PDE4431 coursework, involving an Epson VT6 industrial robotic arm using Epson RC+ 8.0.

The task focuses on implementing a pick-and-place operation to transfer three balls from a fixed pickup position to three designated drop positions.

## Implementation

- Robot movement and position programming
- Pick-and-place sequence
- Approach and retract movements
- Gripper control using digital outputs
- Subroutine-based programming
- Tool Centre Point (TCP) configuration
- Position offsets
